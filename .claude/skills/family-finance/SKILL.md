# 가구 자산·소비 점검

가족 여러 명의 금융 파일을 한 PC에 모아 가구 단위로 본다.
숫자 집계는 Python 스크립트가 하고, 판단과 해석은 이 스킬이 한다.
**화면의 숫자를 직접 계산하지 않는다.** 스크립트가 낸 값을 그대로 인용한다.

## 1. 요청에 따라 무엇을 하나

| 사용자가 말한 것 | 할 일 |
|---|---|
| "가계 점검해줘", "소비 분석해줘" | 3절 전체를 순서대로 |
| "고정비 찾아줘", "새는 돈 찾아줘" | 3절을 돌린 뒤 고정비 섹션만 설명 |
| "보험 점검해줘" | 4절. 소비 자료가 있으면 3절을 먼저 돌려 대조에 쓴다 |
| "카드내역 합쳐줘" | 3절의 parse.py 까지만 |
| 처음 쓰는 사람 | 5절 준비 안내부터 |

## 2. 경로와 실행 명령

`PY` 는 이 PC에서 실제로 뜨는 Python 명령이다. `python --version` → `py -3 --version`
→ `python3 --version` 순으로 시도해 **버전이 찍히는 첫 명령**을 쓴다. Microsoft Store
창이 열리면 그 명령은 버리고 다음 후보로 넘어간다.

`PROJ` 는 이 저장소 폴더다. 경로에 한글·공백이 있을 수 있으니 **항상 큰따옴표로 감싼다.**

```
PY -X utf8 "PROJ/scripts/parse.py"
PY -X utf8 "PROJ/scripts/parse.py"  --input "data/private"
PY -X utf8 "PROJ/scripts/report.py"
PY -X utf8 "PROJ/scripts/report.py" --data  "data/private"
```

`-X utf8` 을 빼지 않는다. 빼면 콘솔에서 한글이 깨진다.

기본은 `data/sample`(가상 예시)이다. 진짜 데이터를 쓸 때는 **두 명령 모두** 경로를 바꿔야 한다.
`parse.py` 는 `--input`(거래 파일이 든 사람별 폴더), `report.py` 는 `--data`(가족·자산·보험 파일이 든 폴더)다.
사용자가 어느 쪽인지 말하지 않았으면 **먼저 묻는다.**

## 3. 소비 점검 절차

1. `parse.py` 를 돌린다. 콘솔에 읽은 파일 수·거래 건수·기간·사람별 합계가 찍힌다.
2. `[!]` 로 시작하는 줄이 있으면 **그 파일은 읽히지 않은 것이다.** 5절로 간다.
3. `report.py` 를 돌린다. `out/우리집_점검.html` 이 만들어진다.
4. 콘솔의 `검산:` 줄에서 구성원 합계와 가구 총지출이 **같은지 확인한다.** 다르면 사용자에게 알리고 멈춘다.
5. 결과를 3~5문장으로 설명한다. 이때 **숫자는 콘솔 출력에서 그대로 가져온다.**
   - 가구 총지출과 구성원별 비중
   - 고정비 월 합계와 연환산 금액
   - 지난달 대비 가장 크게 달라진 카테고리
   - 중복 의심이 있으면 몇 쌍이고 합계가 얼마나 부풀 수 있는지
6. HTML 파일 경로를 알려주고, **표의 줄을 누르면 상세가 펼쳐진다**고 안내한다.

고정비 목록을 설명할 때 **"이건 해지하세요"라고 말하지 않는다.** 마지막 결제일과
판정 근거를 짚어주고, 확인해볼 만한 것을 질문 형태로 제시한다.

## 4. 자산과 보험 — 직접 적어 넣는 자료

카드·은행 파일과 달리 **가족 명단·자산·보험은 자동으로 읽지 않는다.** 서류가 집집마다 다르다.
`report.py` 가 `--data` 폴더에서 아래 세 파일을 찾아 있으면 대시보드에 넣는다. 없으면 그 섹션만 빠진다.

| 파일 | 없으면 |
|---|---|
| `가족.csv` | 거래가 있는 사람만 가족으로 본다. **하린처럼 거래도 보험도 없는 가족은 존재 자체를 모른다** |
| `자산.csv` | 자산 현황 섹션이 빠진다 |
| `보험.csv` | 보험 점검 섹션과 확인 항목이 빠진다 |

파일이 없으면 `templates/README.md` 를 읽고 작성법을 안내한다.
사용자가 증권 사진·PDF·엑셀을 주면 **읽어서 양식에 맞게 채워주고, 사용자가 확인한 뒤 저장하게 한다.**
확인 없이 저장하지 않는다.

스크립트가 계산해 화면에 넣는 것: 보장 항목 × 가족 표, 중복·공백, 실손 세대, 만기 임박,
증권과 실제 출금 대조, 보험료 비중, 상담 질문.

**증권 ↔ 출금 대조가 이 도구의 핵심이다.** 가계부 앱은 소비만, 보험 앱은 보험만 보기 때문에
*내가 내고 있는 줄도 모르는 보험*은 어느 쪽에서도 잡히지 않는다.

사용자가 결과를 물으면 화면에 나온 사실을 그대로 설명하고, **무엇을 물어볼지**까지 짚어준다.
어떤 상품이 더 낫다거나 갈아타라는 말은 하지 않는다.

## 5. 막혔을 때

| 콘솔에 보이는 것 | 상황과 안내 |
|---|---|
| `글자 인코딩을 알 수 없습니다` | 엑셀에서 열어 `CSV UTF-8` 로 다시 저장하게 안내한다 |
| `컬럼을 찾지 못했습니다` | 메시지에 그 파일의 실제 컬럼이 찍혀 있다. `scripts/parse.py` 의 `CONFIG > 컬럼별칭` 에 그 이름을 한 줄 추가한다 |
| `엑셀 파일을 열지 못했습니다` | 옛날 `.xls` 이거나 암호가 걸린 파일이다. `.xlsx` 로 다시 저장하게 안내한다 |
| `거래표가 없습니다` | `parse.py` 를 먼저 돌린다 |
| `3개월 이상 자료가 쌓이면` | 고정비 판정에는 최소 3개월이 필요하다. 몇 개월치가 더 필요한지 알려준다 |
| 검산 불일치 | **결과를 설명하지 말고 멈춘다.** 사용자에게 알리고 원인을 함께 확인한다 |

한글이 콘솔에서 깨져 보여도 **파일이 손상됐다고 단정하지 않는다.** 결과 파일을 열어
확인하고, 정상이면 "파일은 정상이고 화면 표시만 깨진 것"이라고 따로 알린다.
자세한 규칙은 [korean-safe-windows](../korean-safe-windows/SKILL.md) 를 따른다.

## 6. ★ 하지 않는 것

- **금융사에 로그인하지 않는다.** 아이디·비밀번호·인증서·계좌번호를 묻지 않는다.
  사용자가 직접 내려받아 폴더에 넣은 파일만 읽는다
- **투자 권유를 하지 않는다.** 무엇을 사라·팔라·비중을 얼마로 하라고 말하지 않는다
- **보험 가입이나 해지를 권유하지 않는다.** 무엇을 가지고 있는지 정리하고 확인할 거리를
  찾아줄 뿐이다. 판단은 사용자가 하고, 필요하면 자격을 갖춘 전문가와 상담하도록 안내한다
- **중복 의심 거래를 자동으로 지우지 않는다.** 표시만 하고 사용자가 정한다
- **숫자를 직접 계산하지 않는다.** 스크립트 출력에 없는 수치는 문장에 쓰지 않는다
- **`data/private/` 나 `out/` 의 파일을 커밋하지 않는다.** 커밋 전에 `git status` 로 눈으로 확인한다
- 결과 HTML 을 메일·메신저로 보내지 않는다. 실제 거래 내역이 들어 있다

## 7. 파일 위치

| 무엇 | 어디 |
|---|---|
| 진짜 데이터 (사람별 폴더) | `data/private/<사람이름>/` |
| 가상 예시 데이터 | `data/sample/` |
| 합쳐진 거래표 | `out/거래통합.csv` (엑셀에서 바로 열림) |
| 대시보드 | `out/우리집_점검.html` |
| 보험 입력 양식 | `templates/보험_입력양식.csv`, 작성법은 `templates/README.md` |
| 컬럼 별칭·카테고리 규칙 | `scripts/parse.py` 맨 위 `CONFIG` |
| 고정비 판정 기준 | `scripts/report.py` 맨 위 `금액편차한도`, `결제일편차한도` |
