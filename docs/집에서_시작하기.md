# 집에서 이어서 쓰기

교육장 PC에 있던 것을 집에서 그대로 이어 쓰는 방법입니다.
**코드는 깃허브에 다 올라가 있고, 내 금융 데이터는 안 올라가 있습니다.** 그게 맞는 상태예요.

## 1. 집 PC에 파이썬 (한 번만)

[python.org](https://www.python.org/downloads/) 에서 내려받아 설치합니다.
설치 화면 맨 아래 **"Add Python to PATH"를 꼭 체크**하세요. 이것만 놓치면 나중에 안 됩니다.

이미 깔려 있으면 넘어가세요. 확인은 명령창(cmd)에서:

```bash
python --version
```

## 2. 코드 받기

```bash
git clone https://github.com/dg2002-kr/family-finance-check.git
cd family-finance-check
```

깃이 없으면 깃허브 저장소 페이지에서 **Code → Download ZIP** 으로 받아 풀어도 됩니다.
다만 앞으로 계속 고쳐 쓰실 거면 깃을 쓰는 쪽이 낫습니다.

## 3. 잘 도는지 먼저 확인

**`run.bat` 을 두 번 누르세요.** 그게 전부입니다.

- 파이썬을 찾고
- 없는 도구(`openpyxl`)를 알아서 깔고
- 예시 데이터로 대시보드를 만들어
- 브라우저로 띄웁니다

가상 가족의 화면이 뜨면 준비 끝입니다.

## 4. 내 데이터 넣기

`data/private/` 안에 **가족 이름으로 폴더**를 만들고, 내려받은 파일을 넣으세요.

```
data/private/
├─ 아빠/
│   ├─ 신한카드_이용내역.csv
│   └─ 국민은행_거래내역.xlsx
├─ 엄마/
│   └─ 뱅크샐러드_내보내기.xlsx
└─ 아들/
```

| 어디서 받나 | 어떻게 |
|---|---|
| 뱅크샐러드 | 앱 → 가계부 → 내보내기 |
| 카드사 | 홈페이지 → 이용내역 조회 → 엑셀 내려받기 |
| 은행 | 인터넷뱅킹 → 거래내역 조회 → 엑셀 내려받기 |

그리고 **`run.bat` 을 다시 누르면** 내 데이터로 바뀝니다.
`data/private/` 에 폴더가 하나라도 있으면 예시 대신 그쪽을 읽습니다.

## 5. 더 채우면 좋은 것 (선택)

`templates/` 의 양식을 복사해 `data/private/` 에 채워 넣으면 화면이 늘어납니다.

| 파일 | 생기는 것 |
|---|---|
| `가족.csv` | 거래가 없는 가족까지 포함해 **보장 공백**을 찾습니다 |
| `자산.csv` | 자산 현황 탭 |
| `보험.csv` | 보험 점검과 확인 항목 |
| `보유종목.csv` | 주식 종목별 손익 |
| `수혜자규칙.csv` | "누구를 위해 썼나" 구분 |

## 6. AI 분석 (선택)

[AI Studio](https://aistudio.google.com/apikey) 에서 키를 받은 뒤, **폴더 안에서** 이렇게 넣으세요.

```bash
python -X utf8 scripts\set_key.py
```

붙여넣으라는 자리에 키를 붙여넣고 엔터. **화면에 글자가 안 보이는 것이 정상입니다.**
`data/private/gemini.key` 에만 저장되고 깃허브에 올라가지 않습니다.

들어 있는 키를 확인하려면 `python -X utf8 scripts\set_key.py --show`.

그다음,

```bash
python -X utf8 scripts\advise.py
python -X utf8 scripts\ai_setup.py --who
python -X utf8 scripts\report.py
```

1회 약 1.3원입니다. 요약이 그대로면 호출을 건너뛰어 토큰이 들지 않습니다.
**키는 저장소에 넣지 마세요.** 환경변수나 `data/private/gemini.key` 에만 둡니다.

## 휴대폰으로 보고 싶다면

대시보드는 파일 하나라서 **집 안 와이파이에서 휴대폰으로 볼 수 있습니다.**
PC에서:

```bash
python -m http.server 8000 --directory out
```

휴대폰 브라우저에서 `http://<PC의 아이피>:8000/우리집_머니리포트.html` 로 접속하세요.
PC 아이피는 명령창에서 `ipconfig` 로 확인합니다.

> 데이터는 집 PC에 그대로 있고 같은 와이파이 안에서만 보입니다.
> **대시보드 파일을 메신저나 메일로 보내지 마세요.** 실제 거래 내역이 들어 있습니다.
