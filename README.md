# 우리집 가계 점검 (family-finance-check)

가족이 각자 내려받은 **카드·은행·가계부 파일을 한 표로 합쳐**, 가구 전체의 소비와
고정비를 한 화면에서 보는 도구입니다. 보험 증권까지 같은 흐름에서 점검합니다.

가계부 앱은 대개 **개인 계정 단위**라 가구 전체가 안 보이고, **소비 분석과 보험 점검이
따로** 놀아서 한 번에 확인하기 어렵습니다. 그 두 가지를 메우려고 만들었습니다.

```
카드·은행·가계부 파일을 폴더에 넣기
        ↓  parse.py     여러 양식 → 한 표
        ↓  report.py    집계 → HTML 대시보드
요약을 보고, 궁금한 줄을 누르면 그 안의 거래가 펼쳐집니다
```

### 이 도구가 다르게 보는 것

**누가 냈나가 아니라, 누구를 위해 썼나.**
아이 학원비가 엄마 카드에서 나가면 보통은 전부 엄마 지출로 잡힙니다.
그러면 정작 알고 싶은 *"우리 아이한테 한 달에 얼마가 드나"* 를 볼 수 없습니다.
이 도구는 **결제자**와 **수혜자**를 나눠서, 두 가지를 다 보여줍니다.

예시 데이터에서는 결제 기준으로 엄마가 9,200만원이지만,
수혜자 기준으로는 가족공통 4,880만 · 아빠 3,097만 · 딸 2,032만 · 아들 1,906만으로 갈립니다.

**소비와 보험과 자산을 한 화면에서.**
증권 목록과 실제 출금을 맞춰봐서 *증권에 없는데 매달 나가는 보험료* 를 찾아냅니다.
가계부 앱은 소비만, 보험 앱은 보험만 보기 때문에 어느 쪽에서도 잡히지 않는 것입니다.

## 이 도구가 하지 않는 것

- **금융사에 로그인하지 않습니다.** 아이디·비밀번호·인증서를 묻지 않습니다.
  직접 내려받아 폴더에 넣은 파일만 읽습니다
- **데이터가 PC 밖으로 나가지 않습니다.** 네트워크로 아무것도 보내지 않고, 인터넷이 끊겨도 돕니다
- **투자나 보험 가입·해지를 권유하지 않습니다.** 숫자를 모아 정리하고 확인할 거리를 찾아드릴 뿐입니다.
  판단은 본인이 하시고, 필요하면 자격을 갖춘 전문가와 상담하세요

## 준비물

- Windows 10/11 (macOS·Linux도 동작합니다)
- Python 3.10 이상
- `openpyxl` 하나 — 엑셀 파일을 읽을 때만 필요합니다. CSV만 쓰면 없어도 됩니다

```bash
python -m pip install openpyxl
```

그 밖에는 아무것도 설치하지 않습니다. pandas도, 차트 라이브러리도 쓰지 않습니다.

## 5분 체험 — 가상 데이터로 돌려보기

저장소에 **5인 가족 · 12개월 · 거래 1,494건**짜리 가상 예시가 들어 있습니다.
맞벌이 부부와 초6·초4·6세 자녀, 월 소비 약 1,250만원, 총자산 30억원.
명절·여름휴가·학기초가 반영돼 월별 지출이 1,053만~1,397만원 사이로 움직입니다.

```bash
git clone https://github.com/dg2002-kr/family-finance-check.git
cd family-finance-check
python -X utf8 scripts/parse.py
python -X utf8 scripts/report.py
```

`out/우리집_점검.html` 을 브라우저로 열면 됩니다.

Claude Code를 쓰신다면 이 폴더를 열고 **"우리집 가계 점검해줘"** 한 마디면 됩니다.

## 내 데이터로 쓰기

### 1. 가족마다 폴더를 만듭니다 — 폴더 이름이 곧 그 사람입니다

```
data/private/
├─ 아빠/
│   ├─ 뱅크샐러드_2026-09.csv
│   └─ 신한카드_이용내역.csv
├─ 엄마/
│   └─ 국민은행_거래내역.xlsx
└─ 아들/
    └─ 체크카드_내역.csv
```

`data/private/` 는 깃허브에 올라가지 않습니다.

### 2. 파일을 내려받아 넣습니다

| 어디서 | 받는 법 |
|---|---|
| 뱅크샐러드 | 앱 → 가계부 → 내보내기 |
| 카드사 | 홈페이지 → 이용내역 조회 → 엑셀 내려받기 |
| 은행 | 인터넷뱅킹 → 거래내역 조회 → 엑셀 내려받기 |
| 증권사 | 잔고 조회 → 내려받기 |

**CSV든 엑셀이든, 컬럼 이름이 달라도 됩니다.** 흔한 이름은 미리 알고 있습니다.

### 3. 가족·자산·보험을 적어 넣습니다 (선택)

`templates/` 의 양식 세 개를 복사해 `data/private/` 에 채워 넣으면 대시보드에 섹션이 추가됩니다.
작성법은 [templates/README.md](templates/README.md) 를 보세요.

| 파일 | 넣으면 생기는 것 |
|---|---|
| `가족.csv` | 거래도 보험도 없는 가족까지 포함해 **보장 공백**을 찾습니다 |
| `자산.csv` | 자산 현황 섹션 |
| `보험.csv` | 보험 점검 섹션과 확인 항목 |
| `수혜자규칙.csv` | 가맹점을 누구 몫으로 볼지. 없으면 결제자 기준으로만 봅니다 |

### 4. 돌립니다

```bash
python -X utf8 scripts/parse.py --input data/private
python -X utf8 scripts/report.py --data data/private
```

`parse.py` 는 거래 파일을, `report.py` 는 가족·자산·보험 파일을 읽습니다. **두 곳 다 경로를 바꿔야 합니다.**

## 결과 보는 법

대시보드는 **요약 한 장**이고, **누를수록 잘게 나뉩니다.**

```
월별 막대 8월  →  교육 340만  →  청담어학원 68만  →  9월 10일 결제 (원본 파일 197행)
   1번 클릭        2번 클릭          3번 클릭             4번 클릭
```

어디서 들어가느냐에 따라 나뉘는 순서가 다릅니다.

| 누른 곳 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 월별 막대 | 카테고리 | 가맹점 | 개별 거래 |
| 막대 안의 **색 구간** | (그 사람 몫만) 카테고리 | 가맹점 | 개별 거래 |
| 누구를 위해 썼나 | 카테고리 | 가맹점 | 개별 거래 |
| 어디에 썼나 | **누구 몫** | 가맹점 | 개별 거래 |
| 고정비 항목 | 월 | 개별 거래 | — |

개별 거래까지 내려가면 **원본 파일 이름과 몇 번째 행인지**가 적혀 있어, 모든 숫자를 원본까지 되짚을 수 있습니다.

| 섹션 | 무엇을 보나 |
|---|---|
| 맨 위 | 가구 총지출과 지난달 대비, 12개월 흐름 |
| 카드 4개 | **총자산** / 매달 나가는 고정비 / 월평균 수입 / 확인할 항목 |
| **누구를 위해 썼나** | 수혜자 기준. **수혜자 합 = 가구 합 검산**을 함께 표시 |
| 누구 카드에서 나갔나 | 결제자 기준. 위와 숫자가 다른 것이 정상입니다 |
| 월별 추이 | 달마다 누구 몫이 얼마였는지 쌓은 막대 |
| 어디에 썼나 | 카테고리 도넛과 목록 |
| 매달 빠져나가는 고정비 | 월 금액과 **1년이면 얼마인지**, 마지막 결제일, **왜 고정비로 봤는지 근거** |
| 지난달과 달라진 것 | 카테고리별 증감액·증감률 |
| **자산 현황** | 부동산·금융자산·현금 비중과 항목별 금액 |
| **보험 점검** | 보장 항목 × 가족 표, 가입한 증권 목록 |
| **확인해볼 것** | 중복·공백·만기·증권과 출금 불일치 + 상담할 때 물어볼 문장 |

### 고정비는 이렇게 판정합니다

매달 빠짐없이 · 한 달에 한 번 · **금액이 평균의 ±10% 안** · **결제일이 ±3일 안**.
기준은 `scripts/report.py` 맨 위에서 바꿀 수 있습니다.

판정 근거(몇 개월 중 몇 개월, 금액 편차, 결제일)를 화면에 그대로 적어둡니다.
**프로그램은 그 지출이 필요한지 알 수 없습니다.** 근거를 보고 직접 걸러내시라는 뜻입니다.

### 중복 의심 거래는 지우지 않습니다

가계부 앱과 카드사 파일에 같은 결제가 함께 들어 있으면 두 번 잡힙니다.
자동으로 지우면 진짜 거래를 지울 수 있어서, **표시만 하고 얼마나 부풀 수 있는지 금액으로 알려드립니다.**

## 보험 점검

`templates/보험_입력양식.csv` 에 증권을 옮겨 적고 `data/private/보험.csv` 로 저장한 뒤,
Claude Code에서 **"보험 점검해줘"** 라고 하면 됩니다. 작성법은 [templates/README.md](templates/README.md) 에 있습니다.

정리해 드리는 것:

- 보장 항목 × 구성원 표
- **중복** — 같은 사람이 같은 보장을 두 군데서 (실손·배상책임은 중복 보상이 안 된다는 점도 함께)
- **공백** — 그 보장이 아예 없는 사람
- 만기·갱신 12개월 이내
- **소비 내역과 대조** — 증권에 없는데 매달 나가는 보험료, 증권은 있는데 출금이 없는 보험
- 설계사·보험사에 그대로 물어볼 **상담 질문 목록**

마지막 대조가 핵심입니다. 가계부 앱은 소비만, 보험 앱은 보험만 보기 때문에
**내가 내고 있는 줄도 모르는 보험**은 어느 쪽에서도 안 잡힙니다.

## 자주 막히는 곳

| 콘솔에 보이는 것 | 이렇게 하세요 |
|---|---|
| `글자 인코딩을 알 수 없습니다` | 엑셀에서 열고 `CSV UTF-8` 형식으로 다시 저장 |
| `컬럼을 찾지 못했습니다` | 메시지에 **그 파일의 실제 컬럼이 찍혀 있습니다.** `scripts/parse.py` 의 `CONFIG > 컬럼별칭` 에 그 이름을 한 줄 추가 |
| `엑셀 파일을 열지 못했습니다` | 옛날 `.xls` 이거나 암호가 걸린 파일입니다. `.xlsx` 로 다시 저장 |
| 카테고리가 엉뚱하게 잡힘 | `CONFIG > 카테고리규칙` 에 가맹점 이름을 추가 |
| 고정비가 안 나옴 | 3개월치가 모여야 판정됩니다 |

Claude Code를 쓰신다면 **에러 메시지를 그대로 붙여넣기만 하면** 됩니다.
메시지에 파일명·실제 컬럼·고칠 위치가 다 들어 있어서 한 줄 추가로 끝납니다.

## 한계

- 금융사 자동 연동이 없어 파일을 직접 내려받아야 합니다
- 고정비 판정은 규칙 기반이라 오탐·누락이 있습니다. 그래서 판정 근거를 화면에 공개합니다
- 중복 거래를 자동으로 합치지 않습니다
- 약관 PDF 분석은 아직 없습니다 (증권 기준 정리까지 지원)
- 이 도구는 **정보 정리 도구이며 투자·보험 자문이 아닙니다**
