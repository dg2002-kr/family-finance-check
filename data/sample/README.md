# 예시 데이터 (전부 가상입니다)

도구가 어떻게 동작하는지 보여주려고 **지어낸 자료**입니다.
등장하는 가족·회사·금액은 실제와 아무 관계가 없습니다.

## 어떤 가족인가

| 사람 | 나이 | 설명 |
|---|---|---|
| 아빠 | 46 | 직장인 · **통장에 한 해 들어오는 돈 2억원** (세전 약 2억 6천만원) |
| 엄마 | 46 | 직장인 · 월 실수령 620만원 |
| 딸 | 12 | 초등 6학년 |
| 아들 | 10 | 초등 4학년 |
| 막내 | 6 | 거래도 보험도 없음 — **보장 공백이 어떻게 잡히는지 보려고 일부러 비워둠** |

맞벌이 5인 가구 / **월 소비 약 1,215만원** / **월 수입 약 2,234만원** / **총자산 30억원** (부동산 20억 · 금융자산 8억 · 현금 2억)
2024년 10월 ~ 2026년 9월, 파일 6개, 거래 2,988건.

### 아빠 소득을 어떻게 잡았나

통장에 찍히는 건 세전 연봉이 아니라 4대보험과 세금을 뺀 실수령액입니다.
**통장 기준 연 2억**에 맞추려면 세전 연봉이 2억 6천만원쯤 되어야 합니다
(공제대상 가족 4명 — 맞벌이라 배우자 제외, 자녀 3명 — 기준 실수령률 77% 안팎).

| 언제 | 얼마 |
|---|---|
| 매달 25일 급여 | 14,500,000원 × 12 = 174,000,000원 |
| 3월 성과급 | 18,000,000원 |
| 설·추석 상여 | 4,000,000원 × 2 = 8,000,000원 |
| **연 실수령** | **200,000,000원** (세전 약 2.6억의 77%) |

2024년과 2025년 금액에는 연도배수(0.93 · 0.97)가 곱해져 있어 해마다 조금씩 오릅니다.
공제액은 간이세액표를 그대로 옮긴 값이 아니라 그 수준을 본떠 잡은 값입니다.

금액 규모는 아래 공개 통계를 참고해 그럴듯하게 잡은 것이지, 특정 가구의 실제 자료가 아닙니다.

- 초등학생 1인당 월평균 사교육비 (국가데이터처 2025년 조사): 전체 43.3만원 / 참여 학생 51.2만원
- 가계동향조사 소득 5분위 가구 월평균 소비지출 (2025년): 약 494~520만원
- 4대보험 요율 (2026년): 국민연금 4.5%(소득상한) · 건강보험 3.545% · 장기요양 건보료의 12.95% · 고용보험 0.9%

## 파일 구성

```
data/sample/
├─ 가족.csv                      ← 가족 명단 (공백 판정에 필요)
├─ 자산.csv                      ← 부동산·금융자산·현금 16건 (증권사 6곳·은행 3곳)
├─ 보험.csv                      ← 증권 9건, 보장 24줄
├─ 아빠/
│   ├─ 신한카드_이용내역.csv       (CP949, 날짜 2026.01.08, 금액 콤마, 환불 음수)
│   └─ 국민은행_거래내역.csv       (BOM 없는 UTF-8, 출금·입금 분리, 금액에 '원', 날짜 2026/01/02)
├─ 엄마/
│   ├─ 국민카드_내역.xlsx          (헤더가 4행부터, 위 3행은 안내문)
│   └─ 뱅크샐러드_가계부.csv        (UTF-8 BOM, 수입·지출 구분 컬럼)
├─ 딸/체크카드_내역.csv      (컬럼 3개뿐인 최소 형식)
└─ 아들/체크카드_내역.csv
```

컬럼 이름도 파일마다 일부러 다릅니다 — `이용일자`/`거래일시`/`날짜`, `이용하신곳`/`가맹점명`/`적요`/`내용`.

## 일부러 심어둔 함정

실제 카드사·은행 파일에서 흔히 겪는 문제들입니다. 파서가 이걸 통과하면 집에서 받은 진짜 파일도 대체로 읽힙니다.

- **CP949 인코딩** (신한카드) — UTF-8로는 안 읽히는 파일
- **헤더 행 위치** (국민카드 xlsx) — 위 3행이 안내문
- **출금·입금 분리** (국민은행) — 컬럼 2개를 부호 하나로 합쳐야 함
- **금액 표기** — `3,450,000` / `452,000원` / 엑셀 숫자값
- **날짜 형식** — `2026.01.08` / `2026/01/02` / `2026-01-08` / 엑셀 날짜값
- **환불 2건** — 카드 내역에 음수로 들어 있어 그달 지출에서 빠져야 함
- **이체 72건** — 카드대금 결제와 자녀 용돈. 두 번 세지 않게 소비에서 제외돼야 함

## 돌리면 이렇게 나와야 합니다

```
읽은 파일 6개 / 거래 2988건 / 기간 2024-10 ~ 2026-09
가구 총지출 291,779,493원 / 총수입 536,221,000원 / 이체 72건
중복 의심 5쌍
검산: 구성원 합계 = 가구 총지출 ✓

고정비 25건 / 월 4,883,876원 / 1년 58,606,510원
자산 3,000,000,000원 (부동산 66.7% · 금융자산 26.7% · 현금 6.7%)
보험 증권 9건 / 확인해볼 것 9가지
```

### 확인할 신호

- **중복 의심 5쌍** — 엄마의 국민카드와 뱅크샐러드에 같은 결제가 겹쳐 있음 (지우지 않고 표시만)
- **중복 구독** — 넷플릭스가 아빠와 딸에게서 각각 빠져나감
- **고정비로 잡혀야 하는 것** — 학원비 4건, 유치원·발레, 관리비, 통신비, 보험료 7건, 구독 4건, 운동 2건
- **고정비가 아니어야 하는 것** — 장보기·외식·쇼핑처럼 날짜와 금액이 들쭉날쭉한 것

### 보험 점검에서 나와야 하는 것

| 신호 | 어떻게 심었나 |
|---|---|
| 실손 2건 (비례보상) | 아빠가 개인 실손(삼성화재)과 회사 단체실손(한화손보)을 함께 가짐 |
| 보장 공백 | 막내 하린은 증권이 한 건도 없음 |
| **증권에 없는데 매달 38,000원 출금** | 거래에는 `라이나생명 치아보험`이 있는데 보험.csv에는 없음 |
| 증권-출금 금액 불일치 (삼성화재) | 아들 어린이보험은 증권에만 있고 출금 기록이 없음 |
| 만기 임박 | 현대해상 자동차보험이 2027-01-14 만기 |
| 실손 세대 안내 | 아빠 2세대(2015) · 엄마 3세대(2018) · 자녀 4세대(2022) |
