# 여기에 진짜 데이터를 넣습니다

이 폴더는 **깃허브에 올라가지 않습니다.** (`.gitignore`로 막혀 있음)

## 넣는 방법

가족 구성원마다 폴더를 하나씩 만들고, 그 안에 내려받은 파일을 넣습니다.
**폴더 이름이 곧 그 사람의 이름입니다.**

```
data/private/
├─ 아빠/
│   ├─ 뱅크샐러드_2026-09.csv
│   └─ 신한카드_이용내역.csv
├─ 엄마/
│   └─ 국민은행_거래내역.xlsx
└─ 아들/
    └─ 체크카드_내역.csv
```

## 파일은 어디서 받나요

| 소스 | 받는 곳 |
|---|---|
| 뱅크샐러드 | 앱 → 가계부 → 내보내기 |
| 카드사 | 각 카드사 홈페이지 → 이용내역 조회 → 엑셀 내려받기 |
| 은행 | 인터넷뱅킹 → 거래내역 조회 → 엑셀 내려받기 |
| 증권사 | 잔고 조회 → 내려받기 |

CSV든 엑셀이든 상관없습니다. 컬럼 이름이 달라도 됩니다.

## 주의

- 이 폴더의 파일은 **내 PC 밖으로 나가지 않습니다.** 네트워크로 아무것도 보내지 않아요
- 가족 데이터를 모으기 전에 **가족에게 먼저 동의를 구하세요**
- `out/` 폴더에 만들어지는 대시보드에도 실제 거래 내역이 들어 있습니다. 메신저나 메일로 공유하지 마세요
