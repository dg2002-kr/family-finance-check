# 직접 적어 넣는 자료 세 가지

카드·은행 내역은 내려받은 파일을 폴더에 넣기만 하면 되지만,
**가족 명단 · 자산 · 보험**은 집집마다 서류가 달라 자동으로 읽지 않습니다.
표 몇 줄로 옮겨 적으면 나머지는 도구가 해줍니다.

세 파일 모두 `data/private/` 안에 두세요. 거기 있는 것은 깃허브에 올라가지 않습니다.

| 만들 파일 | 복사할 양식 | 없으면 |
|---|---|---|
| `data/private/가족.csv` | `가족_입력양식.csv` | 거래가 있는 사람만 가족으로 봅니다 |
| `data/private/자산.csv` | `자산_입력양식.csv` | 자산 현황 섹션이 빠집니다 |
| `data/private/보험.csv` | `보험_입력양식.csv` | 보험 점검 섹션이 빠집니다 |

채워진 모습은 `data/sample/` 안의 같은 이름 파일을 보시면 됩니다. 전부 지어낸 내용입니다.

---

## 1. 가족.csv — 누가 우리 가족인지

이 파일이 있어야 **"이 사람만 보장이 없다"** 를 찾아낼 수 있습니다.
거래도 없고 보험도 없는 가족(어린 자녀 등)은 여기 적지 않으면 도구가 존재 자체를 모릅니다.

| 칸 | 적는 것 | 예 |
|---|---|---|
| 사람 | `data/private/` 의 폴더 이름과 **똑같이** | `아빠` |
| 관계 | 본인 / 배우자 / 자녀 / 부모 | `자녀` |
| 생년월 | `2014-03` | |
| 비고 | | `초등 6학년` |

---

## 2. 자산.csv — 무엇을 얼마나 가지고 있나

**분류는 `부동산` · `금융자산` · `현금` · `부채` 네 가지**를 씁니다. 이 이름 그대로 써야 묶여요.

| 칸 | 적는 것 | 예 |
|---|---|---|
| 사람 | 명의자. 공동 명의면 `공동` | `아빠` |
| 분류 | 위 네 가지 중 하나 | `금융자산` |
| 세부항목 | 알아볼 수 있는 이름 | `연금저축펀드` |
| 기관 | 은행·증권사 | `미래에셋증권` |
| 평가금액 | 숫자만. 오늘 기준 값 | `95000000` |
| 기준일 | 언제 기준인지 | `2026-09-20` |
| 비고 | | `세액공제 상품` |

`부채`로 적은 줄은 자산에서 빼서 **순자산**을 함께 보여드립니다.

> 계좌번호는 적지 마세요. 기관 이름과 금액이면 충분합니다.

---

## 3. 보험.csv — 보장 항목 하나에 한 줄

증권 한 장에 보장이 여러 개면 **줄을 여러 개** 씁니다.
같은 증권의 두 번째 줄부터는 **월보험료를 비워두세요.** (두 번 더해지지 않게)

| 칸 | 적는 것 | 예 |
|---|---|---|
| 사람 | 폴더 이름과 똑같이 | `아빠` |
| 보험사 | | `삼성화재` |
| 상품명 | 증권에 적힌 이름 | `실손의료비` |
| 증권번호(뒤4자리) | **뒤 4자리만.** 전체를 적지 마세요 | `5567` |
| 계약일 | `2015-03-02`. **실손은 이 날짜로 세대를 판단합니다** | |
| 만기일 | `2045-03-02`, 종신이면 `종신` | |
| 월보험료 | 숫자만. 증권당 한 번만 | `58000` |
| 보장항목 | 아래 목록에서 고르세요 | `실손_급여` |
| 보장금액 | 숫자만. 한도가 없으면 `무한` | `50000000` |
| 갱신형 | `갱신형` 또는 `비갱신` | |
| 비고 | 감액·면책·자기부담 조건 | `2세대 표준형 자기부담 20%` |

### 보장항목 이름 — 가족끼리 똑같이 쓰세요

이름이 제각각이면 중복과 공백을 못 찾습니다.

```
사망_일반   사망_재해   후유장해
암_일반암   암_유사암   뇌혈관질환   허혈성심장질환
입원일당    수술비      간병_장기요양
실손_급여   실손_비급여
자동차_대인배상1  자동차_대인배상2  자동차_대물배상
자동차_자기신체사고  자동차_자기차량손해
운전자_벌금  운전자_형사합의  배상책임  화재_재물  치아
```

## 점검 받기

Claude Code에서 **"우리집 가계 점검해줘"** 라고 하면 대시보드에 다 담겨 나옵니다.
보험만 보고 싶으면 **"보험 점검해줘"**.

정리해 드리는 것:

- **보장 항목 × 가족 표** — 누가 무엇을 얼마나 가지고 있는지, 누가 비어 있는지
- **중복** — 같은 사람이 같은 보장을 두 군데서. 실손·배상책임은 여러 건 들어도 실제 손해액까지만 나온다는 점도 함께
- **실손 세대** — 계약일로 1~4세대를 판단해 자기부담이 얼마인지 안내
- **만기·갱신** — 1년 안에 오는 것
- **소비 내역과 대조** — 증권에 없는데 매달 나가는 보험료, 증권은 있는데 출금이 없는 보험, 금액이 안 맞는 경우
- **상담 질문** — 설계사·보험사에 그대로 물어볼 문장

마지막 대조가 이 도구의 핵심입니다. 가계부 앱은 소비만, 보험 앱은 보험만 봐서
**내가 내고 있는 줄도 모르는 보험**은 어느 쪽에서도 잡히지 않습니다.

## 알아두실 것

- 이 도구는 **어떤 보험을 들거나 해지하라고 권하지 않습니다.** 무엇을 가지고 있는지 정리하고,
  확인할 거리와 물어볼 질문을 찾아드릴 뿐입니다
