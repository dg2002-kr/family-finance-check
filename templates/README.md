# 보험 입력 양식 쓰는 법

보험은 파일 형식이 집집마다 달라서 자동으로 읽지 않습니다.
**증권 한 장을 이 표 몇 줄로 옮겨 적으면**, 나머지는 Claude가 해줍니다.

## 1. 양식 복사하기

`보험_입력양식.csv`를 복사해서 `data/private/보험.csv` 로 저장하세요.
(`data/private/` 안에 두어야 깃허브에 올라가지 않습니다.)

채워진 모습은 `보험_예시_가상.csv` 를 보시면 됩니다. 전부 지어낸 내용입니다.

## 2. 채우기 — 보장 항목 하나에 한 줄

증권 한 장에 보장이 여러 개면 **줄을 여러 개** 씁니다.
같은 증권의 두 번째 줄부터는 **월보험료를 비워두세요.** (두 번 더해지지 않게)

| 칸 | 적는 것 | 예 |
|---|---|---|
| 사람 | `data/private/` 의 폴더 이름과 똑같이 | `아빠` |
| 보험사 | | `삼성생명` |
| 상품명 | 증권에 적힌 이름 | `무배당 종신보험` |
| 증권번호(뒤4자리) | **뒤 4자리만** 적으세요. 전체를 적지 마세요 | `4821` |
| 계약일 / 만기일 | `2018-04-10` 형식. 종신이면 `종신` | |
| 월보험료 | 숫자만. 증권당 한 번만 | `142000` |
| 보장항목 | 아래 목록에서 고르세요 | `암_일반암` |
| 보장금액 | 숫자만. 한도가 없으면 `무한` | `30000000` |
| 갱신형 | `갱신형` 또는 `비갱신` | |
| 비고 | 감액 조건, 면책 기간 등 | `10년 갱신` |

## 3. 보장항목 이름 — 가족끼리 맞춰 쓰세요

이름이 제각각이면 중복·공백을 못 찾습니다. 아래 이름을 그대로 쓰시는 걸 권합니다.

```
사망_일반   사망_재해   후유장해
암_일반암   암_유사암   뇌혈관질환   허혈성심장질환
입원일당    수술비      간병_장기요양
실손_급여   실손_비급여
자동차_대인배상  자동차_대물배상  자동차_자기신체사고
운전자_벌금  운전자_형사합의  배상책임
화재_재물   치아
```

목록에 없는 보장은 그냥 증권에 적힌 대로 쓰셔도 됩니다.

## 4. 점검 받기

Claude Code에서 이렇게 말하면 됩니다.

```
보험 점검해줘
```

그러면 이런 것들을 정리해 드립니다.

- 보장 항목 × 가족 구성원 표 — 누가 무엇을 얼마나 가지고 있는지 한눈에
- **중복** — 같은 사람이 같은 보장을 두 군데서 들고 있는 경우
- **공백** — 가족 중 그 보장이 아예 없는 사람
- **만기·갱신 도래** — 12개월 안에 끝나는 것
- **소비 내역과 대조** — 증권에 없는데 매달 빠져나가는 보험료, 증권은 있는데 출금이 없는 보험
- **상담 질문 목록** — 설계사나 보험사에 물어볼 것

마지막 대조가 이 도구의 핵심입니다. 가계부 앱은 소비만 보고 보험 앱은 보험만 봐서,
**"내가 뭘 내고 있는지도 모르는 보험"** 은 어디에서도 안 잡힙니다.

## 알아두실 것

- **실손의료비·배상책임은 여러 개 들어도 실제 손해액까지만 나옵니다.** 두 개 가입이 두 배 보상이 아닙니다
- 이 도구는 **어떤 보험을 들거나 해지하라고 권하지 않습니다.** 무엇을 가지고 있는지 정리하고, 확인할 거리를 찾아드릴 뿐입니다
